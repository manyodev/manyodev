Optimization

The practical application of derivatives to find the optimal—meaning the absolute maximum or absolute minimum—value of a given real-world or geometric quantity.

To optimize a quantity \(Q\) it must be expressed as a continuous function \(Q\ = f(x)\) on a valid physical domain. The optimal result is found at either a critical number (where \(f'(x) = 0\) or \(f'(x)\) is undefined) or at an endpoint of the domain.

\(d = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}\)

  • If \(f'(x) > 0\) for all \(x < c\) and \(f'(x) < 0\) for all \(x > c\), then \(f(c)\) is the absolute maximum value of \(f\) on the interval.
  • If \(f'(x) < 0\) for all \(x < c\) and \(f'(x) > 0\) for all \(x > c\), then \(f(c)\) is the absolute minimum value of \(f\) on the interval.

Rolle's Theorem

Let \(f\) be a function that satisfies the following three hypotheses:

  1. \(f\) is continuous on the closed interval \([a,b]\)
  2. \(f\) is differentiable on the open interval \((a,b)\)
  3. \(f(a)=f(b)\)

Then there is a number \(c\) in \((a,b)\) such that \(f'(c)=0\)

Mean Value Theorem

Let \(f\) be a function that satisfies the following:

  1. \(f\) is continuous on the closed interval \([a,b]\)
  2. \(f\) is differentiable on the open interval \((a,b)\)

Then there is a number \(c\) in \((a,b)\) such that

\(f'(c)={f(b)-f(a) \over b - a}\)

or, equivalently,

\(f(b)-f(a)=f'(c)(b-a)\)

Antiderivatives

A function \(F\) is called an antiderivative of \(f\) on an interval \(I\) if \(F'(x )=f(x)\) for all \(x\) in \(I\).
